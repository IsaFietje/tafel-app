# Tafelapp

Een simpele app om de tafels van vermenigvuldigen te bekijken en te oefenen.

## Functionaliteiten
- De tafel van een gekozen getal tonen (1 tot 10)
- De tafel oefenen met willekeurige quizvragen
- Score bijhouden tijdens het oefenen

## Gebruik
1. Open `index.html` in je browser.
2. Vul een getal in en klik op "Toon de tafel" om de tafel te zien.
3. Klik op "Start oefenen" om een quiz te beginnen.
4. Type je antwoord en klik op "Controleer".

## Technologieën
- HTML, CSS en JavaScript
- Bootstrap 5
